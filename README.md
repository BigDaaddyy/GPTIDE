# GptIDE

基于 VSCodium / VS Code 开源构建的 Windows IDE。AI 聊天随软件内置，不需要用户安装插件。当前是对开源编辑器完整运行包的定制版本，尚非从 VS Code 源码重编译的独立分支。

## 使用

双击 `启动GptIDE.cmd`。在软件内选择 **文件 → 打开文件夹**，选项目目录，自动读取该项目上次的 GptIDE 聊天及匹配的 Cursor 历史。聊天下拉列表可切换对话，Ctrl+L 打开聊天。首次使用点击 ChatGPT 登录；本机已有有效 Codex 登录时会读取其登录状态。

Agent 仅在打开项目文件夹后显示。默认离线读取项目进度，发送或登录时才启动后端；可在配置中启用打开项目时连接。无项目窗口不提供聊天输入框，也不启动聊天后端。

0.8 起 Agent 严格绑定一个项目根目录，多根工作区不显示 Agent。对话、Tab、草稿、任务和文件引用都按项目隔离。旧原生会话核对实际工作目录后迁移；归属不符或无法核对的记录保留在本地隔离记录中，不进入历史列表。Cursor 多根共享工作区不导入到单个项目。

新对话创建新 Tab；关闭 Tab 保留会话。历史用于找回当前项目的有效会话，空白 Tab 不进入历史，有未发送内容的保留为草稿。名称、内容、工具结果及改动相同的重复记录合并显示，原始记录不删除。

0.23 起悬停消息，点击 **⑂** 从该处创建分支。新 Tab 只复制截至该消息的公开内容，不继承原线程、任务、检查点或草稿；原对话保留。首次发送才建立独立 Codex 会话并附加历史摘录，未确认失败后重试仍带原背景；长历史会提示按配置上限截取最近部分，完整原文保留。分支在历史中独立显示并可重开恢复。分支不会回滚项目文件，代码仍保持当前状态。

发送时暂时锁定重复提交，任务开始后可立即准备下一条草稿。确认只清理已提交版本，后续重新输入相同文字及新增附件保留；旧确认不会影响新任务。准备阶段可停止，长 Cursor 历史确认期间保持当前对话。

0.24 运行期间按发送快捷键或点击 **＋** 将下一条加入当前对话队列；主发送按钮仍可停止当前任务。队列支持编辑、排序、移除和暂停，成功完成后依次执行；失败、停止或重开项目时暂停。上次发送未确认的条目需检查历史后明确重试，避免重复操作。最多 10 条、约 100 万字符存储总量，过大引用会拒绝入队；普通引用是入队时文本快照，固定文件执行前读取最新内容。队列按项目和对话保存，不在后台切换到其他对话执行。

0.26 任务失败、停止或上次结果未确认时显示恢复入口。**连接**只恢复连接，不重发任务；**取回指令**只写入空草稿，不发送，已有草稿保留。窗口重开不会推测上次任务成功，也不会自动恢复队列。首次准备失败的请求同样保留，恢复期间的新输入不会被旧回复覆盖。

只支持 ChatGPT 会员认证，不配置 API Key，不自动切换 API 付费。会员额度与其他 Codex 使用共享，额度耗尽会显示后端错误；软件不会购买额度。模型来自官方返回的列表，首选 GPT-6.1 Sol。

Agent 模式可以修改项目；Ask 模式使用只读沙盒，Plan 模式先调查并输出实施计划。需要额外授权的操作会在 IDE 弹窗中显示。模型旁可选官方支持的推理强度。

## 0.2 版交互

- 左侧文件树、中间原生代码编辑器、右侧内置 Chat。Ctrl+L 聚焦聊天，Ctrl+Shift+L 新建对话。
- 历史按钮打开可搜索的项目对话列表，区分 Cursor 和 GptIDE；菜单支持重命名、删除本地对话、刷新和登录。
- 点击 `@文件` 选择项目文件，或点击当前文件按钮引用编辑器文件/选区。编辑器中 Ctrl+Shift+K 将选区附到聊天。
- 支持流式 Markdown、代码块复制、表格、消息复制、停止生成和滚动回最新消息。
- 长对话默认显示最近 100 条，点击加载更早消息继续查看；流式输出保留其他消息节点。
- 任务过程可展开查看命令输出、退出码、耗时、文件修改和工具状态，复制输出或点击文件路径打开。日志随聊天保存在本机，每对话最多 200 个步骤，每步骤输出保留最后 12000 字符。不会记录隐藏推理或工具参数；没有明确完成事件的旧记录显示“未确认结果”。
- Agent 通过文件修改工具产生的文本改动可逐文件查看差异、保留或撤销，无须项目已有 Git 仓库。撤销前检查当前内容和未保存编辑，发生后续改动时拒绝覆盖。0.21 起终端文本改动也纳入本轮检查点；二进制、超限或未采集内容仍应从 Git 查看。

0.15 起修改记录按对话保留多个轮次，默认最多 20 个检查点、每项目缓存 128 MiB，可在设置调整。下拉切换轮次，点击文件查看该轮修改前后；“当前”比较该轮结果与现在的文件。撤销或重做前核对磁盘内容和未保存编辑，遇到后续改动拒绝覆盖；恢复直接写入磁盘，不触发保存格式化，使用检查点“重做”恢复。

0.21 起每轮 Agent 结束后比较前后快照，终端产生的文本改动也纳入“本轮改动”。同期手动编辑可能一并显示，不能自动认定全部由 Agent 产生；请先查看差异。原内容未知或初始采集不完整时不推测新文件的空基线，保留恢复冲突检查。

最多采集 2500 个文本文件，每轮约 32 MiB，每文件 512 KiB，跳过二进制、依赖和构建目录；普通项目的 app/data 源码目录保留。内容按哈希去重并校验，缺失或损坏会提示。命令面板“GptIDE: 清理未引用检查点缓存”保留当前记录、备份和冲突副本引用，仅清理超过一分钟的无引用内容块。聊天及预览保存在本机 `data/`，不要把该目录上传到 GitHub。

## Ctrl+K 改写（0.6）

在可信任的项目中选中代码，按 Ctrl+K，输入修改要求。没有选区时在光标处生成代码。使用 ChatGPT 会员模型及只读生成会话，不使用 API Key。生成后打开原生代码差异视图，点击通知中的“应用修改”或“放弃”；点击进度通知可取消生成。原文件在生成或预览期间发生变化时拒绝应用。

修改只应用到原文档，不自动保存。可用 Ctrl+Z 撤销。0.25 起输入浮层显示在代码选区附近，Enter 生成、Shift+Enter 换行、Esc 取消，中文输入法回车不误提交；文档变化或关闭时结束输入。结果使用完整原生差异编辑器预览并明确应用，输入/生成/预览期间不会同时启动聊天或队列。旧运行包回退到原生输入框。生成超时为 120 秒，每个原文件限制 512 KiB，附近上下文各约 4000 字符；使用 `example-project/inline-demo.js` 可体验。

首次构建会初始化本软件专用的 Ctrl+K / Ctrl+Shift+K 键位，避免 VS Code 默认组合键前缀冲突。已有 `data/user/User/keybindings.json` 不会被覆盖；自定义过键位的用户可从命令面板运行“GptIDE: 改写选中代码”或自行绑定。

## Cursor 历史

GptIDE 历史保存时保留 `.bak` 上一份备份；主文件损坏时尝试恢复并显示提示，损坏原文会保留。两份都无法读取时暂停发送，请先修复本地记录，避免覆盖证据。草稿按对话保留在编辑器本地状态中。

0.17 增加记录结构与项目归属校验，主记录错放时只恢复归属匹配的备份；恢复后首次写入保留原记录，不覆盖正确备份。无法恢复时禁用输入、发送和新建；手动修复后点击“重新读取项目进度”重载窗口。

同项目多窗口保存使用进程锁及版本校验。发生冲突时主历史不被覆盖，本窗口内容保留在同目录 `.conflict-*.json`，点击刷新重新加载；当前不自动合并冲突对话。进程崩溃留下的锁会在确认原进程已结束后清理。

启动或打开项目后，按完整目录路径匹配 `%APPDATA%/Cursor/User/workspaceStorage`，从 SQLite 快照读取 composer 和 bubble 数据，保留原文件。首次打开默认显示最近的一条；以后优先恢复 GptIDE 上次的对话。刷新可重新读取 Cursor 最近进度。

Cursor 对话只能作为上下文迁移，不能恢复 Cursor 内部代理状态、未完成工具调用、检查点或隐藏的推理内容。首次在导入对话发送消息时，创建新的 Codex 对话；过长历史会提示并发送最近约 18 万字符，全部原文仍可查看。支持本机默认用户目录和显式自定义目录；仅绑定单根项目，不导入多根共享工作区的历史。

## 导入 VS Code 设置和插件（0.9）

按 Ctrl+Shift+P，运行 **GptIDE: 导入 VS Code 设置和插件**。选择默认或自定义 VS Code User / extensions 目录，勾选设置、快捷键和插件。默认保留 GptIDE 同名配置，也可选择覆盖；内置 Agent 快捷键和认证配置保留。主题随对应主题插件迁移。

原配置备份及结果位于 `data/imports/`。插件从本机已安装目录生成临时 VSIX，交给原生安装器；已安装插件保留当前版本，不兼容或失败项显示在结果中。完成后重载窗口。扩展依赖可能由原生安装器下载；不迁移登录凭据、插件缓存、禁用状态或其他用户 Profile。受产品限制的插件不保证能在 GptIDE 运行。

0.16 起导入目标为当前 GptIDE 用户 Profile。设置和快捷键一起校验，失败时尝试还原本次写入；遇到其他窗口的新修改会停止，原文备份保留。插件流式打包，单包最多 512 MiB，包含符号链接或打包期间变化时跳过。取消停止后续打包和安装，已经导入的内容保留；正在执行的原生安装需等待结束。无实际配置变更时保留原注释。

## 配置与用量（0.11）

0.22 配置入口打开独立的 **GptIDE 配置** Tab。可选择用户或当前项目范围，查看来源、重置单项；顶部显示当前会话模型/强度、当前或新连接超时、下一任务权限。默认模型与强度用于新项目，已有会话可在聊天下拉框选择；超时变更用于新连接。

配置控件显示所选范围的值，旁边注明当前生效值与来源。保存期间其他配置控件暂时锁定，输入中的值和焦点不会被刷新清除。项目固定上下文需点击保存，未保存内容有状态提示，可用“还原输入”恢复最近保存的内容。

配置页下方可保存项目固定文件、开发规则及固定引用排除目录。文件使用项目相对路径，每行一项，最多 20 个；规则最多 30000 字符，固定上下文每次读取最多约 60000 字符，并占用引用总预算。重开项目恢复，发送时读取最新内容；排除项仅控制固定引用，不改变 Agent 沙箱权限。存储位于项目独立的 `data/projects/*.context.json`，保留备份并拒绝覆盖另一窗口的新配置。

状态栏用量、GPT 账户菜单以及首页“用量”读取本机 Codex 最近记录和 GptIDE 缓存，明确显示采集时间，不能当成实时账户查询。没有缓存显示未知；不会连接模型、购买额度或使用重置券。正在使用的聊天收到用量通知时保存最新缓存。

0.20 状态栏随新缓存更新，默认每 60 秒只读刷新本机记录。`gptide.usage.autoRefreshSeconds` 设为 0 可关闭定期读取；缓存默认超过 15 分钟或窗口已过期时不显示当前百分比，用量列表保留旧记录并注明“当前未知”。可通过 `gptide.usage.staleAfterMinutes` 调整缓存年龄，软件不会推算重置后的额度。

命令面板运行“GptIDE: 会话与 Codex 配置”，可打开会话设置、已有的 Codex config.toml、用量和本机诊断。配置包括连接开关、超时、推理强度、授权策略、Agent 网络权限、默认模式、发送键和导入背景长度。关闭自动连接后可离线读取项目，发送或登录才连接。授权和网络设置遵循[官方配置说明](https://learn.chatgpt.com/docs/config-file/config-reference)；沙箱始终限制项目范围，不提供全盘写入模式。

## 对话查找与导出（0.14）

聊天中按 Ctrl+F，搜索当前对话的全部消息；上一条/下一条按消息导航。很早的结果以最多 100 条附近记录展示，点击“返回最新消息”恢复最新部分。Esc 关闭查找。

更多菜单或命令面板可导出完整 Markdown，不受界面分页限制；任务日志和未发送草稿可选。导出运行中对话会标注当前快照。任务过程提供轮次选择、仅失败和复制当前筛选日志，不会把“命令完成”推断为“测试通过”。

## Agent 问答（0.17）

Agent 请求补充信息时使用原生选项或输入框；支持自定义选项及敏感输入遮蔽，取消不自动选择答案。已结束轮次、已解决的问题和失效连接不会沿用授权。回答只回传到发起请求的连接，不写入普通聊天或导出日志。授权提示显示命令、原因、工作目录和请求写入目录，只允许此次操作。

任务、文件恢复或 Ctrl+K 预览进行中不切换 GPT 账户。无项目窗口保留一个登录流程；关闭窗口、登录完成或打开浏览器失败时释放该流程。

## 输入快捷操作（0.19）

输入 `/` 打开命令，方向键选择，Enter / Tab 执行，Esc 收起。支持 `/new`、`/ask`、`/agent`、`/plan`、`/file`、`/selection`、`/diagnostics`、`/diff`、`/folder`、`/usage`、`/settings`、`/find`、`/export`、`/terminal`。例如 `/ask 解释这段代码` 切到 Ask 并发送后面的文字；未识别命令按普通内容处理。

独立 `@` 打开上下文菜单，选择后进入原生文件等选择流程，不自动连接模型。保留引用标记前后的文字；邮箱中的 @ 不触发。任务运行期间只显示用量、配置等可用工具操作。

## 构建和数据

从 GitHub 克隆后，先安装 Node.js 24 或更新版本及 Codex，然后在项目根目录执行 `powershell -ExecutionPolicy Bypass -File tools/setup.ps1`。脚本下载固定版本的官方 VSCodium，验证 SHA-256，解压完整运行包并构建内置聊天。Git 仓库不包含大型第三方运行包、私人聊天数据和认证凭据。

`npm run check`、`npm test`、`npm run build`。`app/` 包含完整 VSCodium 运行环境；`builtin/` 是内置聊天源码；`tools/` 是打包、启动和导入程序；`data/` 为本机编辑器设置及项目聊天。源码不包含登录凭据，Codex 自行管理 ChatGPT 登录。

1.0 验收范围见 [RELEASE_CHECKLIST.md](RELEASE_CHECKLIST.md)。`npm run acceptance` 在独立测试 Profile 和临时项目运行离线界面验收；`npm run acceptance -- --web` 只检查聊天布局、焦点和交互，`--native` 检查完整编辑器。需要开发测试环境中提供 Playwright；已有安装可通过 `GPTIDE_PLAYWRIGHT_MODULE` 指定完整模块路径，浏览器路径可通过 `GPTIDE_CHROMIUM` 指定。报告和截图位于被 Git 忽略的 `downloads/acceptance/`，测试不会连接模型。源码测试不依赖 Playwright。

运行要求：Windows x64，本机有 Codex CLI / Codex 桌面应用。自动发现 `%LOCALAPPDATA%/OpenAI/Codex/bin/*/codex.exe`，也可以在设置里填写 `gptide.codexPath`。

0.27 起启动器为最近项目等原生共享状态指定 `data/shared/`，与其他编辑器和测试 Profile 隔离；原聊天、草稿和检查点继续使用原来的项目数据目录。第一次使用独立共享目录时，最近项目列表会从之后打开的项目开始积累。

底座来源：https://github.com/VSCodium/vscodium/releases/tag/1.135.06055

附带 `example-project/` 可体验打开文件夹自动恢复聊天。若打开 GptIDE 软件源码的整个根目录，VS Code 会把目录内的编辑器模块视作可被项目修改的代码，在未信任该目录时禁用模块；普通项目文件夹不受此影响。

官方会员接入：https://learn.chatgpt.com/docs/app-server

第三方许可随 `app/` 保留。此版本未实现 Cursor Tab 补全、语义索引或 Cursor 私有功能，不应被称为完整 Cursor 复刻。
